# ESP2 — Wi-Fi CSI Transmitter

ESP2 is one of PerryMeter's two Wi-Fi transmitters. It sends packets that ESP1 receives and measures using Channel State Information (CSI).

- **Device:** ESP2
- **Role:** Wi-Fi transmitter
- **Sender MAC:** `1a:00:00:00:00:02`
- **Wi-Fi channel:** 11

The firmware is based on Espressif's ESP-CSI sender example.

For the complete hardware architecture, see [`../../README.md`](../../README.md).
